# AI Introduction: Copilot in Excel Demo

Demo files for the Relogica internal session **"AI Introduction: Trends, tools and what it means for us"**.

Use them to repeat the live demo yourself: give Copilot in Excel a messy dataset, then clean it, analyse it and chart it with plain-language prompts.

## What's inside

| File | What it is |
| --- | --- |
| [AI_Demo_Copilot_Haul_Fleet_Q3-2026.xlsx](AI_Demo_Copilot_Haul_Fleet_Q3-2026.xlsx) | Haul truck shift log for a fictional open-pit coal mine: 12 trucks, 3 pits, 2 shifts, July to September 2026 (2,215 rows). It is exported "as is", so it has typos, mixed Indonesian/English entries, blanks and duplicates to clean. |
| [Copilot_Demo_Prompts.txt](Copilot_Demo_Prompts.txt) | Copy-paste prompts in C.O.R.E format for four steps: understand, clean, analyse and visualise, plus a few bonus challenges. |

## How to try it

1. Download the Excel file: open it here on GitHub, then click **Download raw file**.
2. Save it to your **OneDrive** and turn on **AutoSave**. Copilot in Excel needs this.
3. Click any cell inside the table on the `Haul_Data` sheet, then open **Copilot** from the Home tab.
4. Open the prompts file and paste one prompt at a time.

## About the data

- **Scenario:** a coal mine's haul truck fleet, with one row per truck per shift.
- **Columns:** date, shift, pit, truck, operator, downtime and delay reason, rainfall, trips, payload, cycle time, fuel used and target tonnes. The `About` sheet in the Excel file explains each one.
- **What's hidden:** several business stories are buried in the data. See how many Copilot helps you find.

## Good habits

- Write prompts with **C.O.R.E**: Context, Objective, Role, Expectation.
- Answers can differ a little each time you run a prompt.
- **Always verify** key numbers before you use them in a client report.
- Use only company-approved tools for real work data. This demo data is fictional, so it is safe for any account.
